## 🚀 Featured Project

### ⚙️ Workflow Engine

A production-grade distributed workflow orchestration engine built in **Go**.

It allows users to define workflows as DAGs, execute tasks across distributed workers, integrate with MCP tools, and observe execution in real time.

**Key engineering concepts:**

- DAG-based workflow execution
- Topological sorting and cycle detection
- Distributed worker pool
- Redis Streams based task queue
- Dead-letter queue and retry handling
- Idempotent task dispatch
- PostgreSQL persistence
- REST and gRPC APIs
- JWT authentication and role-based access control
- MCP tool execution
- Prometheus metrics
- OpenTelemetry tracing with Jaeger
- Docker-based local development setup

> This project is designed to demonstrate backend engineering, distributed systems, reliability, and observability fundamentals.
